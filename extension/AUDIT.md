# 0.4.1 自查记录

日期：2026-10-20。范围：扩展安装/更新、页面输入与定位、翻译引擎、异步竞态、网络失败、设置开关、结果展示和搜索跳转。

## 已修复的问题

1. **暂停与启动设置的竞态**：读取设置完成前不翻译；较晚返回的旧设置不覆盖用户的新开关操作。暂停会取消前端任务、后台请求和语言包下载。
2. **旧结果/旧输入泄漏**：更改查询后取消旧任务；异步本机检测结束后再次验证输入，避免把已修改的旧查询发送到在线服务。清空、输入法选字、输入框替换、Esc、点击其他区域和离开页面均处理取消。
3. **本机 API 失败或卡住**：检测/初始化/翻译有等待上限；失败时清理坏引擎并尝试在线服务；超时清理引擎，不永久停留在“翻译中”。真实引擎本身仍依赖浏览器。
4. **下载失败**：同步异常、异步异常、超时有明确提示；重试在真实点击中启动，保留浏览器要求的用户激活。关闭提示后进度和下载完成不再强行弹回；暂停后晚到的模型会释放。
5. **在线额度/错误**：严格解析 true/false；区分 HTTP 限流、额度、服务错误、不完整译文和网络错误；额度受限后短暂冷却，避免连续无效重试。冷却元数据留在浏览器会话内，不含查询内容。
6. **页面兼容与显示**：优先定位 Pinterest 的搜索框，忽略无关 combobox；恢复被页面删除的扩展容器；支持页面替换搜索框、未触发 input 的清空；窄窗口中限制提示框位置。
7. **结果安全与缓存**：服务结果只作为文字显示，不执行 HTML/加载图片；不接受空译文、超长或仍含汉字的不完整译文；同一请求合并，成功结果内存缓存。本机/在线来源在英文的鼠标提示中标明。
8. **设置/更新**：设置读写失败、能力检测失败有可读提示；旧插件上下文失效提示刷新；重复注入不创建重复监听，不同寻词安装实例会提示清理旧版。提供固定版本 ZIP，避免从不同解压目录误加载旧代码。

## 真实检查结果

- 实际 Chromium 154 的主世界和隔离世界中可检测到 Translator API，中文到英文状态为 `downloadable`。
- `node extension/tests/live-native.cjs` 使用真实 API、真实用户点击和真实下载，等待 120 秒后返回 TimeoutError，未获得真实译文。这项检查失败，不能把本机引擎标为端到端通过，也未确定下载失败的完整原因。
- 真实 Pinterest、MyMemory 翻译接口及 Chrome 官方文档请求在云端被出站代理以 CONNECT 403 阻断。无法在这里验证登录页面、在线服务实际译文及用户 Mac 的网络。
- 浏览器管理员策略不允许云端加载未打包扩展；实际扩展安装加载需要本机验证。用户已确认旧版能安装，但不代表新版所有真实行为已通过。
- 安装包生成时核对 manifest 引用、版本和 ZIP 完整性；包中不含测试、凭据、node_modules 或早期独立网页。

## 仍可能遇到的问题

| 场景 | 影响与当前处理 |
| --- | --- |
| Chrome 版本、设备、隐私模式或管理策略不提供本机 API | 无法本机翻译；会使用在线模式，仍有额度/网络限制。不能承诺所有 Chrome/Edge 都有本机引擎。 |
| 首次模型下载被网络、磁盘或浏览器限制阻断 | 不会开始本机翻译；120 秒超时后提示重试。本次云端真实检查就未完成下载。 |
| 在线免费服务限流、额度耗尽、断网或返回错误 | 显示原因并冷却/允许重试；插件不能解除服务商限额。 |
| Pinterest 更新页面结构或使用未声明的地区域名 | 搜索框可能无法定位；需要维护定位或 manifest。当前明确支持的域名见 manifest。 |
| 专有名词、双关、上下文不足 | 通用翻译可能不准确；本次测试没有建立真实翻译质量基准。 |
| 手动安装、复制错文件夹或保留多个版本 | 版本仍需手动更新；重复安装提示减少混淆，但不是应用商店自动更新。 |

结论：已修复审查可复现的问题，自动化交互与故障处理通过；真实翻译端到端尚未通过。不能称为“所有问题已排除”或“保证装好就能稳定翻译”。
